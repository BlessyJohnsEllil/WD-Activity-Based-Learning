## Projects

### 1. Digital Library Management Interface — The Reading Room

**Case Study 05**

A library website interface that presents book information in an organized format.

**Features**
- Navigation links and introductory section
- Book categories
- Six book cards with cover images, titles, authors, descriptions, and availability labels
- Search and filter interface elements
- Book catalog table
- Library rules

**Technologies:** HTML5 and CSS3  
**Layout techniques:** CSS Grid and Flexbox

### 2. Doctor Appointment Booking Interface — CarePlus

**Case Study 12**

A healthcare website interface for viewing doctor profiles and requesting appointments.

**Features**
- Navigation bar and introductory section
- Three doctor profile cards
- Doctor specializations and consultation timings
- Patient registration form
- Fields for name, email, phone number, doctor selection, appointment date, preferred time, and additional information
- Styled buttons and form-field focus effects

**Technologies:** HTML5 and CSS3  
**Layout techniques:** Flexbox

### 3. College Fest Management Website — Ignite 2026

**Case Study 26**

A college festival website presenting event information and participant registration details.

**Features**
- Festival hero banner with background image and overlay
- Six event cards covering technical events, cultural competitions, and workshops
- Event schedule table
- Event coordinator profiles
- Participant registration form
- Festival rules
- Hover transitions and responsive styling techniques

**Technologies:** HTML5 and CSS3  
**Layout techniques:** CSS Grid and Flexbox

## How to Run the Projects

1. Open the project folder in **Visual Studio Code**.
2. Locate the HTML file for the website you want to view.
3. Open the HTML file in a browser, or use the **Live Server** extension in VS Code if it is installed.
4. Keep the related CSS files and image assets in their expected locations so the styling and images load correctly.

## Purpose

These projects demonstrate the use of HTML and CSS to create organized, visually styled interfaces for a digital library, doctor appointment booking, and college festival management.
